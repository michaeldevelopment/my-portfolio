# Sanabria Labs

Personal portfolio for Michael Sanabria — Full Stack AI JS/TS Developer based in Medellín, Colombia.

Dark, image-led, Awwwards-style. Minimal copy, big type, real screenshots.

## Stack

React 19 · TypeScript · TanStack Start & Router · Vite 8 · Tailwind v4 · shadcn/ui

## Development

Requires Node.js 22.12+ and pnpm.

```sh
pnpm install
pnpm dev
```

## Scripts

- `pnpm dev` — start dev server
- `pnpm build` — production build
- `pnpm lint` — ESLint
- `pnpm typecheck` — `tsc --noEmit`
- `pnpm format` — Prettier write
- `pnpm format:check` — Prettier check

## CI/CD

GitHub Actions runs lint, prettier, typecheck and build on every push and PR to `main`. Deploy is gated on a green pipeline.

# Sanabria Labs

Build a high-impact, visually driven personal portfolio website for Michael Sanabria, a Full Stack AI JavaScript/TypeScript Developer based in Medellín, Colombia. The target audience is hiring managers, recruiters, and freelance clients. The bar is Awwwards-level: this is an image-led, visual-first site. Copy should be minimal and punchy, never a wall of text. If a section reads like a paragraph, cut it down to a headline plus one short line.

VISUAL IDENTITY

- Dark theme as the base: near-black background (#0A0A0C), off-black card surfaces (#121216)

- Primary accent: electric blue (#2D5BFF) for links, active states, glow effects

- Secondary accent: saturated red (#E63946), used sparingly: hover states on CTAs, one highlighted word in the headline, active nav indicator

- Text: near-white (#F5F5F7) primary, muted gray (#8A8A93) secondary

- Bold, large-scale display typography for headlines, tight tracking. Big type is a visual element, not just a heading.

- No stock photography, no generic illustration packs. Every image is either a real project screenshot or a custom-styled mockup frame.

VISUAL-FIRST CONTENT RULES (read this carefully)

- Every project gets a large preview image, not a text description as the lead element. Text supports the image, never the other way around.

- Where a live URL exists, treat the image as a real, current screenshot of that site inside a clean browser-chrome frame (rounded top bar, dots, address bar showing the real domain).

- Where no live URL exists, use a styled device or browser mockup frame with an abstract UI representation inside it (colored blocks, simplified layout shapes suggesting the app's actual interface, in the site's blue/black/red palette), not a stock image and not empty gray boxes.

- Cut every paragraph-style bio and project description down to a maximum of one short sentence or a few keyword fragments. Move any extra detail into a "view details" hover state or expandable card, not the default view.

- Skills section: tech logo icons in an animated grid or auto-scrolling marquee, no text-heavy bullet lists.

- Experience: a slim visual timeline with a small icon per role and a one-line summary each, expandable on click for the fuller detail.

- WordPress and Divi archive: a full image gallery grid of screenshot thumbnails, each one clickable through to Behance, no descriptive text needed beyond a name label on hover.

ANIMATION AND INTERACTION

- Smooth scroll (Lenis-style easing) across the whole site

- Scroll-triggered reveal animations: images and cards fade/scale into view, staggered for grids

- Custom cursor on desktop: small dot, grows and tints blue on hover, red on primary CTAs

- Magnetic hover effect on buttons and project cards

- Hero: full-bleed animated background (slow gradient mesh, particle grid, or reactive thin lines), restrained and dark, with a strong visual centerpiece (a large mockup collage, a 3D element, or an animated code/terminal visual), not text alone

- Project cards: 3D tilt on hover plus a soft blue glow border, image zooms slightly on hover

- Animated counters for stats (years of experience, projects shipped)

- Respect prefers-reduced-motion, keep loops under about 2 seconds

STRUCTURE (in this order)

1. Hero: name, role, one-line value prop, three CTAs (View my work, Download CV, Start a project), big visual centerpiece

2. About: one short line plus a small visual element (a simple icon strip or a subtle graphic), no long bio

3. Skills and stack: icon grid or marquee, grouped by category, minimal labels

4. Experience: visual timeline, one line per role, expandable for detail

5. Featured projects: five large image-led cards (screenshot or styled mockup, project name, one-line tag, tech icons, GitHub link), two marked "Shipping soon"

6. WordPress and Divi: "Live sites" as two large real screenshots with links, "Archive" as an image thumbnail gallery linking to Behance

7. Certifications: icon badge row, no descriptions

8. Contact: minimal, icon-linked (email, LinkedIn, GitHub, Behance)
